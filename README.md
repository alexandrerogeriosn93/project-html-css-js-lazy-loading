# Lazy Loading Project

This project demonstrates a simple and efficient way to implement **Lazy Loading** for images using the **Intersection Observer API**. The goal is to improve page performance by loading high-resolution images only when they enter the viewport.

## 🚀 Technologies Used

- **HTML5**: For the markup and structure of the page.
- **CSS3**: For styling the layout and image containers.
- **JavaScript**: To implement the lazy loading logic.


## 🛠️ How to Execute

To run this project and see the lazy loading in action, it is recommended to use the **Live Server** extension in VS Code.

### Using Live Server (Recommended)

1. Open the project folder in **VS Code**.
2. If you don't have it yet, install the **Live Server** extension by Ritwick Dey.
3. Right-click on `index.html` in the file explorer.
4. Select **"Open with Live Server"**.
5. The project will open in your default browser at `http://127.0.0.1:5500`.

### Manual Execution

Alternatively, you can simply open the `index.html` file in any modern web browser by double-clicking it in your file explorer.
